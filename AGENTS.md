# LAB_TERMINAL //: System Harness (AGENTS.md)

## System Overview
LAB_TERMINAL is a laboratory-themed React 19 / Vite application backed by a local FastAPI service for telemetry, weather, and research journal persistence.

## Quick Commands
- **Frontend Dev:** `npm run dev` (Runs Vite on http://localhost:5173)
- **Backend Dev:** `python backend/main.py` (Runs FastAPI on http://127.0.0.1:8000)
- **Verification:** `npm run lint` && `npm run build`
